# Updating your profile and practice details

## Update profile information

1. Open **Settings** and select **Your profile**.
2. Update your name and login email. You can also change your profile image.
3. Practice owners can also see practice-wide fields such as phone number, website, registration or tax number, and address.
4. Select the interface language you want to use.
5. Review the changes and select **Save settings**.

The visible fields depend on whether you are the practice owner, an administrator, or a staff member. A missing field usually means that it belongs to the owner or requires permission to administer settings.

Profile and practice details can be reused on invoices, Online Booking, messages, or other product areas. Where a value is displayed still depends on the feature and its own settings; saving a profile value does not make it public everywhere.

## Language settings

Changing the profile language changes the Practize interface after the page reloads. It does not change the Online Booking language or rewrite existing email and SMS templates. Review Online Booking and message settings separately when your practice changes language.

## SMS sender details

Authorized administrators can configure the SMS sender name or sender phone number on **Your profile**. The sender name has a limited length, and the phone field accepts the format enforced by the form. Use a valid sender phone number when clients must be able to reply. Availability and display of sender controls can depend on country and messaging configuration.

Saving sender settings does not send a message or confirm carrier delivery.

## If changes do not save

- Correct the validation message beside an invalid phone number, address, registration number, or other field.
- Check whether the field is restricted to the owner or an authorized administrator.
- Save before leaving the page, then reload to confirm the displayed value.
- Review Online Booking and message templates separately after changing language or practice details.

Use the current **Your profile** screen to verify saved account values and permissions. Do not put login details, private addresses, registration documents, or other sensitive account information into a product-help question.
