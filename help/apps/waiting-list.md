# Waiting List

Keep requests for unavailable appointment times and support waiting lists for classes where configured.

## Availability and permissions

Open **Settings → Apps** and find **Waiting List**. The card's availability, price, connection state and available actions apply to your account. A help article does not activate an app. Ask the owner to review missing access; staff permissions and app availability are separate. Do not use another person's login to bypass a restriction.

## Set up

1. Activate Waiting List and open its settings.
2. Enable the calendars that should accept waiting-list requests. Separately review the setting for event waiting lists.
3. Verify that the relevant service or event is publicly available and test the client-facing waiting-list option without creating a real client commitment.

## Everyday use

Review requests when availability changes and use the existing offer or promotion flow. Confirm that a real reservation exists before recording a reserved check-in.

## Troubleshooting

If no waiting-list option appears, check calendar and event settings separately. A freed place may still have waiting-list priority, so Attendance can block a walk-in until that process is resolved.

## Limits and changes

A waiting-list entry does not guarantee a place, payment or admission. Do not manually bypass existing waiting-list priority. See [Classes and events](https://help.practize.io/help/apps/events).
