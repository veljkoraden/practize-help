# Workfeed

Workfeed is a third-party partner tile in the legacy Apps interface. Availability depends on country and the interface shown for your account.

## Availability and permissions

Open **Settings → Apps** and find **Workfeed**. The card's availability, price, connection state and available actions apply to your account. A help article does not activate an app. Ask the owner to review missing access; staff permissions and app availability are separate. Do not use another person's login to bypass a restriction.

## Set up

1. Open the Workfeed tile if it is shown and read the third-party notice.
2. Use the provider link supplied in the tile to review current onboarding and supported integration scope. The Practize tile is an introduction, not proof of a connected account.
3. Complete the provider-owned setup with the appropriate account owner and verify the intended practice, data sharing and billing terms.
4. Check the real end-to-end result with the provider before using the workflow operationally.

## Everyday use

Maintain the connection using the provider-supported process. Workfeed’s legacy introduction describes synchronizing shift schedules to a Practize calendar; verify the actual configured calendar before relying on those times.

## Troubleshooting

If the tile is absent, do not assume the integration is enabled for your country or current interface. If setup or synchronization fails, use the provider support contact shown in the tile and include the relevant reference, never passwords or API secrets.

## Limits and changes

Partner onboarding, pricing and supported capabilities are controlled by the external provider. This guide does not certify current provider readiness or promise a direct native settings page. Follow the link in the current Apps tile rather than an old bookmarked setup URL.

## Related help

Return to [App help](https://help.practize.io/help/) to find related setup guides. Before changing a connected workflow, finish pending work and verify its status in the relevant booking, invoice or client record.
