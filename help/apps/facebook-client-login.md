# Facebook client login

Offer Facebook sign-in in client workflows where the connection is supported and available.

## Availability and permissions

Open **Settings → Apps** and find **Facebook client login**. The card's availability, price, connection state and available actions apply to your account. A help article does not activate an app. Ask the owner to review missing access; staff permissions and app availability are separate. Do not use another person's login to bypass a restriction.

## Set up

1. Check the app card and available activation action for the current practice.
2. Activate through the displayed setup flow and review any required public booking/client-login configuration.
3. Test the actual client sign-in flow with an authorized account and verify it resolves to the intended client.

## Everyday use

Use the normal sign-in screen. If a client cannot use Facebook, follow the other supported login or verification options shown by the practice.

## Troubleshooting

A provider cancellation or unavailable sign-in should not be treated as a completed login. Check the public flow and current provider availability before promising this option to clients.

## Limits and changes

This is a sign-in option, not a Facebook advertising or page-management integration. The existence of a catalog card does not verify current provider approval for every environment.
